How Reinforcement Learning Works

Core concepts used by this simulation

01 · Agent

The purple AI agent interacts with the environment. It observes its current state and chooses an action such as moving up, down, left or right.

02 · Reward

The environment provides feedback. Reaching the goal produces a positive reward, while hitting obstacles or taking unnecessary steps produces penalties.

03 · Q-Learning

The Q-table stores the expected value of each action. The agent repeatedly explores the environment and updates these values to learn a better policy.
